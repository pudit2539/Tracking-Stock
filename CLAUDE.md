# Claude Project Instructions

## 1. 🚀 Automatic Production Deployment
- Whenever any bug fix, feature, or code modification is completed, automatically commit all changes and push to `origin main` to trigger Vercel Production deployment (`https://tracking-stock.vercel.app`).
- Never leave finished changes unpushed.

## 2. 💾 Persistent Context & Engineering Log (PROJECT_LOG.md)
- Always refer to `PROJECT_LOG.md` for system architecture, database schema, LINE Bot webhook patterns, and incident changelog.
- Whenever you make changes, update `PROJECT_LOG.md` with what was changed, root cause, and how it was resolved.
