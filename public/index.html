สามารถเพิ่มได้หลายคน และหลายกลุ่มพร้อมกัน

ประเภท ชื่อเรียกปลายทาง Target ID สถานะรับข้อความ จัดการ
💡 เวลาระบบส่งเตือนอัตโนมัติ จะส่งหาทุกปลายทางที่เปิดสถานะ "ใช้งาน" พร้อมกัน

คู่มือการเชื่อมต่อ LINE (แบบละเอียด)

ขั้นตอนเปิดใช้งานและนำ Group ID มาใส่

1 สร้าง Channel ใน LINE Developers

เข้าเว็บ developers.line.biz > Login > สร้าง Provider > สร้าง Channel ประเภท Messaging API

2 คัดลอก Channel Access Token

ไปที่แท็บ Messaging API > เลื่อนลงล่างสุดคลิก Issue ที่หัวข้อ Channel access token (long-lived) แล้วคัดลอกมาวางในช่องด้านซ้าย

3 วิธีหา User ID หรือ Group ID (สำคัญมาก!)

• ถ้าส่งเข้าไลน์ส่วนตัว: ดูในแท็บ Basic settings ในหัวข้อ Your user ID (ขึ้นต้นด้วย U...)

• ถ้าส่งเข้าไลน์กลุ่ม: เชิญ LINE Bot เข้ากลุ่ม จากนั้นพิมพ์ id ในกลุ่ม บอทจะตอบกลับเป็น Group ID (ขึ้นต้นด้วย C... หรือ R...) นำมาใส่ในช่องได้ทันที!

💡 ปลายทางทดสอบ:

หลังจากใส่ Token และ ID ครบแล้ว ให้กดปุ่ม "🔔 ทดสอบส่งข้อความ" ระบบจะส่งข้อความว่า "✅ ทดสอบการแจ้งเตือน LINE สำเร็จ..." เข้าไลน์ของคุณทันทีเหมือนในภาพตัวอย่างครับ!
